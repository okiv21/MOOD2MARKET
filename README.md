# Mood2Market
### AI-Powered Bitcoin Sentiment Analysis & Price Prediction

Mood2Market is a full-stack Bitcoin intelligence platform that combines deep learning price forecasting with real-time dual sentiment analysis from financial news and social media. Built as an undergraduate dissertation project, it demonstrates that integrating sentiment signals from multiple sources alongside historical price data produces measurably better directional accuracy than price-only models.

---

## Overview

Traditional cryptocurrency forecasting relies solely on price history. Mood2Market challenges this by incorporating two independent sentiment streams — institutional news via GDELT and retail investor sentiment via Reddit — processed through FinBERT, a BERT-based model pretrained on financial text. These sentiment features are merged with Bitcoin OHLCV data and fed into a custom PyTorch LSTM model that forecasts 90-day price trajectories.

The result is a live Streamlit dashboard that displays real-time BTC price data, FinBERT sentiment scores, LSTM forecasts, and AI-generated chart interpretations powered by the Groq LLM API.

## Key Results

| Model | MAE (log return) | RMSE (log return) | Directional Accuracy |
|-------|-----------------|-------------------|----------------------|
| LSTM  | 0.01480 | 0.01967 | **63.9%** |
| TCN   | 0.01480 | 0.01967 | **63.9%** |
| ARIMA | 0.04188 | 0.06158 | 45.2% |

- LSTM and TCN outperform ARIMA by **64% on MAE** — confirming sentiment features add predictive value
- **63.9% directional accuracy** on the Feb 2026 crash test set
- LSTM trading strategy outperformed buy-and-hold by **8 percentage points** during the crash period
- Reddit sentiment led the Nov 2025 BTC price decline by several days (score: −0.96 at $94,594)

## Models

### LSTM (Primary)
- 2-layer stacked LSTM · 128 hidden units · Dropout 0.2
- Predicts `log_return` (not raw price) for recursive stability
- 10 input features: price indicators + FinBERT news + Reddit sentiment scores
- HuberLoss · Adam · ReduceLROnPlateau · best-weight checkpointing
- 80/10/10 chronological train/val/test split · 30-day sequence length

### TCN (Comparison)
- Pure PyTorch dilated causal convolutions · 4 residual blocks · dilation 1/2/4/8
- Same feature set as LSTM · Severe overfitting on 434-row dataset confirmed data bottleneck

### ARIMA(2,1,2) (Baseline)
- Price data only · walk-forward validation
- 45.2% directional accuracy confirms price series alone are insufficient

## Sentiment Pipeline

1. **Collection** — GDELT news articles (keywords: Bitcoin, BTC, cryptocurrency) and Reddit posts (r/Bitcoin, r/BTC, r/BTCTrading, r/BTCMarkets) via PRAW
2. **Cleaning** — language filtering, spam removal, BTC keyword filter, deduplication
3. **FinBERT scoring** — per-article positive/negative/neutral probabilities
4. **Aggregation** — daily averages with forward-fill for news gaps and missingness indicator for Reddit
5. **Merge** — joined to BTC OHLCV data on date key → `merged_dataset.csv`

> FinBERT performance benchmark: F1 = 0.88 on Financial PhraseBank (Araci, 2019). Applied in inference mode without fine-tuning.
